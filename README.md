# 桌面待办

一个轻巧的 Windows 桌面待办卡片。离线使用，无需账号，任务保存在本机。

**下载**：在 [Releases](https://github.com/Yaohua-Leo/DesktopTodo/releases/latest) 页面下载 `DesktopTodo.exe`，双击即可运行（单文件、免安装）。

自行构建时，双击 `dist\DesktopTodo.exe` 运行。

## 使用方法

- **添加任务**：在底部输入内容，按 Enter 或点击加号。
- **完成任务**：点击任务前面的圆圈，文字会加上删除线；再点一次可恢复待办。
- **设置截止时间**：鼠标移到任务上点击 📅（或右键“设置截止时间”），在弹出面板中先选日期、再选小时，精确到整点。任务文字下方显示截止状态：未到期灰绿、今天到期绿色、过期未完成红色；已完成变灰加删除线。面板中的“清除截止时间”可移除。
- **日历视图**：点击“📅 日历”展开或折叠月历。有截止的日期显示小圆点；周六周日和公众假期（香港红日）都显示红色小点，悬停提示和屏幕阅读器标签会说明是“周末”还是具体假期名称（假期正好落在周末时显示假期名）。点击某一天可在下方看到当天到期的任务和时间，并可直接勾选完成。点右上角“完成热力图”切换为按每日完成数量渐变着色的热力图，悬停日期可查看完成数量和任务名；再点一次切回。正反色都只统计到今天为止：未来日期的完成记录不参与色阶，不会抬高或压低已过去日子的深浅。
- **一键反色**：热力图模式下右上角多出“一键反色”。开启后整个色阶反向——完成越多颜色越浅，完成 0 件颜色最深；尚未到来的日期不参与色阶，保持中性底色。
- **每日提醒**：分两个时段。早上（默认 09:00）提醒今天到期的待办，下午（默认 16:00）提醒明天到期的待办，同一天同一时段不重复；弹窗同时列出已过期未完成的任务。两个时段的时间都可在托盘右键菜单的“提醒时间”中分别选择 6 至 22 点，两个时段不会落在同一小时。程序启动时会补齐当天已过点、且尚未提醒过的时段。
- **切换语言**：托盘右键菜单的“语言”中可选简体中文 / 繁體中文 / English，切换后界面文案、日期格式、截止标签、假期名称和提醒弹窗立即生效，无需重启。
- **切换主题**：点击标题栏右上角的三色圆点按钮打开主题画廊，五种主题任选——鼠尾草（默认）、石墨、午夜、猫布奇诺、液态玻璃，每种都有浅色和深色两个版本；画廊底部可切换“跟随系统 / 浅色 / 深色”（跟随系统会随 Windows 深浅模式自动切换）。托盘右键菜单的“主题”和“深浅外观”是同一设置的另一入口。过期红、今天到期绿、已完成灰等语义色在每个主题里单独调校；8 月 17 日的红心不随主题变化。
- **固定到桌面**：默认开启。点击“固定到桌面”切换置顶，让卡片保持在普通应用窗口上方。
- **编辑任务**：双击任务文字，修改后按 Enter 保存；Esc 取消编辑并恢复之前未提交的新任务草稿。右键菜单也可编辑。
- **删除任务**：鼠标移到任务上，点击右侧叉号，或使用右键菜单。“清除已完成”可批量清理；删除后 10 秒内可点击“撤销”，之后仍可从托盘右键菜单的“恢复待办”找回——预览窗支持按时间范围（最近一天/一周/一个月/一年/全部/精确日期）、按任务内容关键词筛选，勾选后恢复，任务会以删除时的状态（完成态、截止时间）回到列表末尾。
- **恢复待办**：数据来自清除/删除时自动写入的归档 `cleared.jsonl`（只增不删），同一任务多次删除时恢复最后一次删除时的样子；已在列表中的任务不会重复恢复。此功能上线之前删除的任务不在归档中，无法恢复。
- **调整卡片**：拖动顶部“桌面待办”区域移动位置；鼠标移到任意边框或四个角，出现双向箭头后拖动即可调整大小。拉高卡片可显示更多任务，尺寸会自动保存。右下角的小手柄也可使用。
- **最小化与收进托盘**：右上角短横线最小化，叉号把卡片收进系统托盘（首次会提示一次），程序继续运行、每日提醒保持有效；单击托盘图标唤回卡片。真正退出请用托盘右键菜单的“退出”；已提交的任务自动保存。再次双击程序同样会唤回已运行的卡片。
- **开机自启**：在托盘右键菜单勾选“开机自启”，登录 Windows 后程序收进托盘自动运行。通过 `--data-dir` 使用自定义数据目录时，自启仍使用默认目录。
- **重新读取**：底部“重新读取”可刷新本机任务，鼠标悬停可查看实际数据目录。启动时文件被短暂占用会自动重试；读取异常会一直显示，并暂停写入，不会把空列表当成正常任务覆盖历史。尚未保存的任务修改或正在编辑时，重新读取会禁用以保护当前内容。

置顶无法覆盖 Windows 安全桌面或部分独占全屏游戏。

## 数据与备份

数据目录为 `%LOCALAPPDATA%\DesktopTodo`，可直接粘贴到文件资源管理器地址栏打开。

| 文件 | 用途 |
| --- | --- |
| `tasks.json` | 任务（含截止时间）、完成状态、置顶、日历、热力图反色、语言、主题与深浅模式、两个提醒时段设置和窗口位置尺寸 |
| `tasks.backup.json` | 上一版任务内容；移动、缩放和重复关闭不会冲掉此备份 |
| `history\*.json` | 任务内容变更的独立历史快照，保留所有版本 |
| `completions.jsonl` | 完成热力图数据源：每次完成追加一行，含完成时间和任务文本快照；删除或清除任务不影响此文件，「恢复待办」会移除对应记录。**注意任务文本会保留在此文件中**，不需要时可手动删除整个文件，热力图从零重新统计 |
| `cleared.jsonl` | 删除/清除任务的归档（只增不删），「恢复待办」的数据源，每行含任务文本、截止时间、完成状态和清除时间。**注意任务文本会保留在此文件中**，不需要时可手动删除整个文件 |
| `*.bad-*.json` / `completions.bad-*.jsonl` | 发现损坏文件（或完成记录坏行）时保留的原始副本 |
| `startup.log` | 启动、读取和保存错误的诊断信息，只记录目录、条数和错误，不记录任务正文 |

请先退出应用，再复制整个数据目录进行手动备份。删除或移动程序文件不会删除该目录中的任务。恢复备份时请先保留当前数据；备份可能不包含最近一次修改。

主文件无法读取时会尝试备份和历史快照。若无法恢复，卡片会暂停保存并显示错误；文件恢复可访问后会自动重新读取。每次保存前会检查磁盘数据是否已被其他实例修改，拒绝使用过期状态覆盖新任务。正常删除后的有效空列表仍保持为空，不会自动复活已删除任务。

## 运行环境

面向 Windows 10 / 11，使用 .NET Framework 4.x，建议 4.8。当前制作环境无需额外安装运行时。交付程序为单个 EXE，无需安装即可运行。

## 开发与验证

在项目目录打开 PowerShell：

```powershell
.\build.ps1
.\tests\run-storage-tests.ps1
.\tests\run-ui-tests.ps1
```

构建脚本调用 Windows 自带的 .NET Framework C# 编译器，生成 `dist\DesktopTodo.exe`。界面 XAML 和图标嵌入 EXE；无需 NuGet 包或网络连接。界面测试需要可用的 Windows 桌面会话。

**发布**：推送 `v*` 标签（如 `v1.0.1`）后，GitHub Actions 会自动构建 exe、运行存储测试并创建 Release（见 `.github/workflows/release.yml`）；带预发布号的标签（如 `v1.0.1-rc.1`）会标记为 pre-release。

| 源文件 | 内容 |
| --- | --- |
| `App.cs` | 启动入口、单实例唤回、任务交互、月历与提醒控制器、主题应用器（ThemeManager）、系统托盘和窗口控制 |
| `MainWindow.xaml` | WPF 卡片布局、月历与截止时间选择面板、主题画廊、样式和数据绑定（颜色全部走 `{DynamicResource Theme*}`） |
| `Theme.cs` | 5 个主题家族 × 浅/深共 10 套调色板（纯数据，无 WPF 依赖）、家族/深浅模式解析、系统深浅读取 |
| `Storage.cs` | JSON 存储、备份及损坏数据保护、完成记录（completions.jsonl）、清除归档（cleared.jsonl）、旧版提醒时间的一次性迁移 |
| `Logic.cs` | 截止文本、月历格子、热力色阶、双时段提醒判定和恢复筛选（去重/时间窗/关键词）的纯逻辑（无界面依赖） |
| `Localization.cs` | 简体中文 / 繁體中文 / English 三语字符串表（含占位符格式化） |
| `Holidays.cs` | 内置的香港公众假期表（2025–2028，含三语名称，键存在性校验） |
| `App.ico` | 程序图标 |
| `app.manifest` | 运行权限、系统兼容及 DPI 声明 |
| `build.ps1` | 构建脚本 |
| `tests\StorageTests.cs` | 存储与纯逻辑验证 |
| `tests\UiTests.cs` | 界面与交互验证 |

开发调试时可用 `DesktopTodo.exe --data-dir <目录>` 指定独立数据目录。
